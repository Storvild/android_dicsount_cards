# DiscountCards

**DiscountCards** 是一款用于方便地存储、扫描和使用忠诚度卡和折扣卡的 Android 应用。该应用让您将所有折扣卡集中保存在一处，借助条形码生成器在收银台快速扫描它们，并对数据进行备份。

> [!IMPORTANT]
> **核心优势：**
> - ⚡️ **即时启动** — 应用在数分之一秒内打开，启动后立即可用，无需等待加载。
> - 🧩 **通过小组件快速访问条形码** — 在桌面上添加一个包含所选条形码的小组件，**无需打开应用本身**即可向收银员出示。
> - 📤 **数据导出与导入** — 以 JSON 或 CSV 格式为所有卡片创建备份，在任意设备上恢复，或将卡片分享给他人。
> - 🚫 **无广告** — 应用完全独立运行，不包含任何广告或追踪器。

## 📱 主要功能

- 💳 **忠诚度卡管理** — 添加、编辑卡片，以及单个或批量删除卡片。
- 📷 **扫描条形码和从文件选择** — 通过相机实时扫描实体卡片（CameraX + ML Kit），或从图库/文件中选择条形码图像。
- 🔢 **支持多种条形码格式** — 使用 ZXing 库生成可视条形码:
  - `QR_CODE`
  - `CODE_128`
  - `EAN_13` / `EAN_8`
  - `UPC_A`
  - `CODE_39`
  - `PDF_417`
  - `AZTEC`
  - `PHONE` (按电话号码享折扣 — 以文本显示，不作为条形码生成)
- 🎨 **个性化** — 从现成的调色板中选择卡片颜色，或通过 HSV 调色板和 HEX 代码（`#RRGGBB`）选择任意颜色，选择类别图标，添加备注和 CVC/CVV 代码。
- ⭐️ **收藏与统计** — 标记常用卡片，自动统计浏览次数。
- 🔍 **智能搜索** — 按商店名称、卡片号码或备注快速搜索。
- 🔀 **卡片排序** — 按名称、创建日期或使用频率方便地排序。
- ⚡️ **紧凑列表模式** — 设置「在列表中显示条形码」（默认开启）。关闭后主屏幕上的条形码和卡片号码生成被禁用，列表项高度减半，从而显著加快加载和滚动速度。
- 💡 **屏幕亮度管理** — 打开卡片时自动设置所选亮度级别，并可通过卡片屏幕上的内置滑块直接快速调整（通过设置中的「在卡片上显示亮度」选项开启，默认关闭）。
- 📤 **卡片共享** — 可将所选卡片与其他用户共享。
- 🌐 **多语言支持** — 在应用设置中单独选择界面语言（支持 11 种语言）。
- 🌗 **主题** — 支持浅色、深色和系统主题。
- 📦 **备份（导出 / 导入）** — 以 **JSON** 或 **CSV** 格式保存数据:
  - 导入模式: **MERGE（合并）** 或 **OVERWRITE（覆盖）**。
  - 灵活的去重策略: *更新现有*、*作为新卡片添加*、*跳过*。
  - 📂 **打开备份文件（「打开方式」）** — 支持从文件管理器直接打开或发送（`ACTION_VIEW`、`ACTION_SEND`）文件（JSON），并自动启动卡片导入对话框。
- 🗃️ **卡片归档** — 将未使用的卡片移至单独的部分:
  - 活动卡片的详情屏幕上有 **「移入归档」** 按钮，归档卡片的详情屏幕上有 **「从归档提取」**。
  - 主屏幕下拉菜单中的 **「归档」** 条目会打开一个带有搜索、列表和空状态的独立屏幕。
  - 归档卡片会隐藏于主列表、搜索、导出和共享（Share）之外。
- 🧩 **桌面小组件** — 可扩展小组件（从 1x1 到 5x5），包含卡片选择、条形码/QR 和商店名称、编辑参数的按钮以及点按快速打开卡片。
- 👆 **长按上下文菜单** — 在列表中长按卡片可快速访问「编辑」和「删除」操作。
- 📱 **Edge-to-Edge UI** — 基于 Material 3 和 Jetpack Compose Adaptive 构建的、考虑系统面板的现代化自适应界面。

## 💾 备份与数据格式

应用支持两种格式: **JSON** 和 **CSV**。

### JSON

```json
[
  {
    "id": 1,
    "storeName": "沃尔玛",
    "cardNumber": "1234567890123",
    "barcodeFormat": "EAN_13",
    "note": "家庭卡",
    "cardColor": "#0EE8A5",
    "iconName": "shopping_cart",
    "isFavorite": true,
    "cvc": "123",
    "usageCount": 5,
    "createdAt": "2026-01-01T10:10:10",
    "updatedAt": "2026-01-01T10:10:10",
    "isArchived": false
  }
]
```

### CSV

带表头 `名称,代码,代码类型,CVC,备注` 的表格:

```csv
名称,代码,代码类型,CVC,备注
沃尔玛,1234567890123,EAN_13,123,家庭卡
永辉,9876543210,QR_CODE,,
```

### 导入模式:
- **MERGE（合并）** — 将文件中的卡片添加到数据库中已有的卡片。
- **OVERWRITE（覆盖）** — 用文件中的数据完全替换当前卡片。

### 卡片匹配时的冲突处理策略:
- **UPDATE_EXISTING（更新现有）** — 更新卡片信息。
- **ADD_AS_NEW（作为新卡片添加）** — 创建新的重复卡片。
- **SKIP（跳过）** — 跳过重复项。

## 🔒 隐私与独立性

**DiscountCards** 是一款完全**离线**的应用。它从根本上**不请求**互联网访问权限（`android.permission.INTERNET`）。

**这给用户带来的好处:**
- 🛡 **绝对隐私:** 您卡片的所有数据、使用历史和备份都本地存储在您的设备上。什么都不会发送到第三方服务器。
- 🚫 **无广告:** 没有互联网，在物理上就无法加载和显示广告或追踪器。
- 🔋 **节省电池:** 没有隐藏的背景同步和网络请求来消耗电池和移动流量。
- ✈️ **不依赖网络:** 卡片在任何地方都能即时加载并生成条形码: 即使在大型超市的混凝土结构中，或没有蜂窝信号的地窖里。

## 📋 所需权限 (Permissions)

应用仅需要一种访问权限，且仅在请求时:

| 权限 | 用途 |
|---|---|
| `android.permission.CAMERA` | 从实体卡片扫描条形码（可选，仅在扫描时请求，`uses-feature required="false"`）。 |
