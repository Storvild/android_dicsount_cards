# DiscountCards

**DiscountCards** は、ロイヤルティカードやディスカウントカードを便利に保存、スキャン、活用するための Android アプリです。アプリはすべてのディスカウントカードを1か所に集め、バーコード生成機能を使ってレジで素早くスキャンし、データのバックアップを作成できます。

> [!IMPORTANT]
> **主なメリット:**
> - ⚡️ **即座の起動** — アプリは数分秒で開き、読み込み待ちなしですぐに使えるようになります。
> - 🧩 **ウィジェットによるバーコードの高速アクセス** — 選択したバーコード付きのウィジェットをホーム画面に追加し、**アプリ自体を開かずに**店員に提示できます。
> - 📤 **データのエクスポートとインポート** — 全カードを JSON または CSV 形式でバックアップし、任意のデバイスで復元したり、他のユーザーと共有したりできます。
> - 🚫 **広告なし** — アプリは完全に自立して動作し、広告やトラッキングトラッカーを一切含みません。

> [!TIP]
> **アプリをダウンロード:**
> - 📦 **リリース APK をダウンロード:** [GitHub Releases](https://github.com/Storvild/android_discount_cards/releases/latest)

## 📱 主な機能

- 💳 **ロイヤルティカードの管理** — カードの追加、編集、個別および一括削除。
- 📷 **バーコードのスキャンとファイルからの選択** — カメラ（CameraX + ML Kit）で実物のカードをリアルタイムにスキャンするか、ギャラリー/ファイルからバーコード画像を選択します。
- 🔢 **多数のバーコード形式に対応** — ZXing ライブラリを使用して視覚的バーコードを生成:
  - `QR_CODE`
  - `CODE_128`
  - `EAN_13` / `EAN_8`
  - `UPC_A`
  - `CODE_39`
  - `PDF_417`
  - `AZTEC`
  - `PHONE` (電話番号による割引 — テキストとして表示され、バーコードとして生成されません)
- 🎨 **カスタマイズ** — 完成済みパレットから色を選択するか、HSV パレットと HEX コード (`#RRGGBB`) で任意の色を選択、カテゴリアイコンの選択、メモおよび CVC/CVV コードの追加。
- ⭐️ **お気に入りおよび統計** — よく使うカードのマーク、閲覧回数の自動記録。
- 🔍 **スマート検索** — 店舗名、カード番号、メモからの高速検索。
- 🔀 **カードのソート** — 名称、作成日、使用頻度での便利なソート。
- ⚡️ **コンパクトなリストモード** — 設定「リストにバーコードを表示」（デフォルトで有効）。無効にするとメイン画面のバーコードおよびカード番号の生成が停止し、リスト要素の高さが半分になり、読み込みとスクロールが大幅に高速化します。
- 💡 **画面輝度の制御** — カードを開いた際に選択した輝度レベルを自動設定し、カード画面内蔵のスライダーですばやく微調整も可能（設定の「カードに輝度を表示」オプションで有効化、デフォルトは無効）。
- 📤 **カードの共有** — 選択したカードを他のユーザーと共有できます。
- 🌐 **言語対応** — アプリ設定で UI 言語を個別選択可能（11 言語対応）。
- 🌗 **テーマ** — ライト、ダーク、システムテーマに対応。
- 📦 **バックアップ（エクスポート / インポート）** — データを **JSON** または **CSV** 形式で保存:
  - インポートモード: **MERGE（マージ）** または **OVERWRITE（上書き）**。
  - 重複処理の柔軟な戦略: *既存を更新*、*新規として追加*、*スキップ*。
  - 📂 **バックアップファイルの開く（「アプリを選択して開く」）** — ファイルマネージャーからの（JSON）ファイルの直接開くまたは送信（`ACTION_VIEW`、`ACTION_SEND`）をカードインポートダイアログの自動起動と併せてサポート。
- 🗃️ **カードのアーカイブ** — 使われていないカードを専用のセクションに移す:
  - 有効なカードの詳細画面には **「アーカイブに移動」** ボタン、アーカイブ済みカードの詳細画面には **「アーカイブから復元」** ボタン。
  - メイン画面のドロップダウンメニューの **「アーカイブ」** アイテムは、検索、リスト、空状態を持つ別画面を開きます。
  - アーカイブ済みカードはメインリスト、検索、エクスポート、共有（Share）から非表示になります。
- 🧩 **ホーム画面のウィジェット** — カード選択、バーコード/QR、店舗名、編集ボタン、タップによるカードの素早い開きに対応した拡張可能なウィジェット（1x1〜5x5）。
- 👆 **ロングプレスのコンテキストメニュー** — リストのカードを長押しすると「編集」と「削除」にすばやくアクセスできます。
- 📱 **エッジトゥエッジ UI** — Material 3 と Jetpack Compose Adaptive に基づくシステムパネルを考慮した最新の適応型インターフェース。

## 💾 バックアップとデータ形式

アプリは **JSON** と **CSV** の 2 つの形式に対応しています。

### JSON

```json
[
  {
    "id": 1,
    "storeName": "ファミリーマート",
    "cardNumber": "1234567890123",
    "barcodeFormat": "EAN_13",
    "note": "家族カード",
    "cardColor": "#0EE8A5",
    "iconName": "shopping_cart",
    "isFavorite": true,
    "cvc": "123",
    "usageCount": 5,
    "createdAt": "2026-01-01T10:10:10",
    "updatedAt": "2026-01-01T10:10:10",
    "isArchived": false
  }
]
```

### CSV

ヘッダー `名前,コード,コードの種類,CVC,メモ` のテーブル:

```csv
名前,コード,コードの種類,CVC,メモ
ファミリーマート,1234567890123,EAN_13,123,家族カード
イオン,9876543210,QR_CODE,,
```

### インポートモード:
- **MERGE（マージ）** — ファイルのカードをデータベースの既存ものに追加。
- **OVERWRITE（上書き）** — 現在のカードをファイルのデータで完全に置き換え。

### カードが重複する場合の競合処理戦略:
- **UPDATE_EXISTING（既存を更新）** — カード情報の更新。
- **ADD_AS_NEW（新規として追加）** — 重複する新しいカードの作成。
- **SKIP（スキップ）** — 重複項目のスキップ。

## 🔒 プライバシーと自立性

**DiscountCards** は完全に**オフライン**で動作するアプリです。本質的にインターネットアクセスへの権限（`android.permission.INTERNET`）を**要求しません**。

**ユーザーへの利点:**
- 🛡 **完全なプライバシー:** カードの全データ、使用履歴、バックアップはすべて端末上にローカルに保存されます。第三者サーバーに何も送信されません。
- 🚫 **広告なし:** インターネットがないため、広告やトラッキングトラッカーの読み込み・表示は物理的に不可能です。
- 🔋 **バッテリー節約:** バッテリーとモバイル通信を消費する隠れたバックグラウンド同期やネットワーク要求はありません。
- ✈️ **ネットワークに依存しない:** どこでもカードが即座に読み込まれ、バーコードを生成できます。ハイパーマーケットのコンクリートの箱や、携帯電話の電波のない地下室でも。

## 📋 必要な権限 (Permissions)

アプリに求められるアクセスは1つだけで、それもリクエスト時にのみ:

| 権限 | 用途 |
|---|---|
| `android.permission.CAMERA` | 実物のカードからのバーコードスキャン（任意、スキャン時のみ要求、`uses-feature required="false"`）。 |
