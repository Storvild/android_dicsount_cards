# DiscountCards

**DiscountCards** — Android-приложение для удобного хранения, сканирования и использования карт лояльности и дисконтных карт. Приложение позволяет хранить все ваши скидочные карты в одном месте, быстро сканировать их на кассе с помощью генератора штрих-кодов и делать резервные копии данных.

## 📱 Основные возможности

- 💳 **Управление картами лояльности** — добавление, редактирование, индивидуальное и массовое удаление карт.
- 📷 **Сканирование и выбор штрих-кода из файла** — сканирование физических карт в реальном времени с помощью камеры (CameraX + ML Kit) или выбор изображения со штрих-кодом из галереи/файла.
- 🔢 **Поддержка множества форматов штрих-кодов** — генерация визуальных штрих-кодов с помощью библиотеки ZXing:
  - `QR_CODE`
  - `CODE_128`
  - `EAN_13` / `EAN_8`
  - `UPC_A`
  - `CODE_39`
  - `PDF_417`
  - `AZTEC`
  - `PHONE` (числовое представление)
- 🎨 **Персонализация** — выбор индивидуального цвета карты, иконки категории, добавление заметок и CVC/CVV кодов.
- ⭐️ **Избранное и статистика** — отметка часто используемых карт, автоматический учёт количества просмотров.
- 🔍 **Умный поиск** — быстрый поиск по названию магазина, номеру карты или заметкам.
- 🔀 **Сортировка карт** — удобная сортировка списка по названию, дате создания или частоте использования.
- ⚡️ **Компактный режим списка** — настройка «Показывать штрихкоды в списке» (по умолчанию включена). При её отключении генерация штрих-кодов и номеров карт на главном экране отключается, уменьшая высоту элементов списка в два раза и значительно ускоряя загрузку и скроллинг.
- 💡 **Максимальная яркость экрана** — автоматическое увеличение яркости дисплея при открытии карты для удобного считывания сканерами на кассе (уровень яркости регулируется в настройках).
- 📤 **Обмен картами** — возможность поделиться выбранными картами с другими пользователями.
- 🌐 **Поддержка языков** — отдельный выбор языка интерфейса в настройках приложения (поддержка 11 языков).
- 🌗 **Темы оформления** — поддержка светлой, тёмной и системной темы.
- 📦 **Резервное копирование (Экспорт / Импорт)** — сохранение данных в JSON-формате:
  - Режимы импорта: **Объединение (MERGE)** или **Перезапись (OVERWRITE)**.
  - Гибкие стратегии обработки дубликатов: *Обновить существующие*, *Добавить как новые*, *Пропустить*.
  - 📂 **Открытие JSON-файлов («Открыть с помощью»)** — поддержка прямого открытия или отправки (`ACTION_VIEW`, `ACTION_SEND`) файлов бэкапов из файловых менеджеров с автоматическим запуском диалога импорта карт.
- 🗃️ **Архив карт** — перенос неиспользуемых карт в отдельный раздел:
  - Кнопка **«Перенести в архив»** на экране деталей активной карты и **«Извлечь из архива»** на экране деталей архивной карты.
  - Пункт **«Архив»** в выпадающем меню главного экрана открывает отдельный экран с поиском, списком и пустым состоянием.
  - Архивные карты скрыты из основного списка, поиска, экспорта и обмена (Share).
  - При сохранении карты через экран добавления/редактирования значения `isArchived` и `usageCount` не сбрасываются.
- 🧩 **Виджеты на рабочий стол** — расширяемый виджет (от 1х1 до 5х5) с выбором карточки, штрихкодом/QR и названием магазина, поддержкой белого или прозрачного фона (с белой подложкой для считывания сканером), кнопкой редактирования параметров и быстрым открытием карты по тапу.
- 👆 **Контекстное меню по долгому нажатию** — быстрый доступ к действиям «Редактировать» и «Удалить» при долгом нажатии на карточку в списке.
- 📱 **Edge-to-Edge UI** — современный адаптивный интерфейс с учётом системных панелей на базе Material 3 и Jetpack Compose Adaptive.

## 🏛 Архитектура

Приложение построено в соответствии с рекомендациями Google по архитектуре Android-приложений (**MVVM + Clean / Layered Architecture**):

1. **UI Layer (Jetpack Compose)**:
   - Экраны (`*Screen.kt`) представлены декларативными Composable-функциями.
   - Состояние интерфейса описывается `UiState` и отслеживается реактивно через `collectAsStateWithLifecycle()`.
2. **ViewModel Layer**:
   - Предоставляет `StateFlow<UiState>` для UI.
   - Обрабатывает действия пользователя и передаёт вызовы в слой данных.
3. **Data Layer (Repository Pattern)**:
   - `CardRepositoryImpl` предоставляет единую точку доступа к картам лояльности (Room DB) и функциям бэкапа.
   - `UserPreferencesRepository` управляет пользовательскими настройками через Android DataStore Preferences.

## 💾 Резервное копирование и формат данных

Данные карт экспортируются в текстовый JSON-файл следующего формата:

```json
[
  {
    "id": 1,
    "storeName": "Пятёрочка",
    "cardNumber": "1234567890123",
    "barcodeFormat": "EAN_13",
    "note": "Карта семьи",
    "cardColor": "#0EE8A5",
    "iconName": "shopping_cart",
    "isFavorite": true,
    "cvc": "123",
    "usageCount": 5,
    "createdAt": "2026-01-01T10:10:10",
    "updatedAt": "2026-01-01T10:10:10",
    "isArchived": false
  }
]
```

### Режимы импорта:
- **MERGE** — добавление карт из файла к существующим.
- **OVERWRITE** — полная замена текущих карт данными из файла.

### Решение конфликтов при совпадении карт:
- **UPDATE_EXISTING** — обновление информации существующей карты.
- **ADD_AS_NEW** — создание новой карты-дубликата.
- **SKIP** — пропуск совпавшего элемента.
